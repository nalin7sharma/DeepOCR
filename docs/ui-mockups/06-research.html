Model voting

2-fold cross-validated on the same test lines

Every model reads each line. The readings are aligned word by word, and each word is decided by a weighted vote, where a vote counts model weight × that model's confidence. A word several models agree on wins over one model's guess.

Real example: “Tin ___ Alley”, five readings
